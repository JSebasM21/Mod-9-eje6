Botones en Bootstrap 5

Bootstrap ofrece componentes predefinidos con estilos consistentes. Solo necesitas la clase base btn más una clase de color.

Rápido Consistente Predefinido

Botones Básicos (Solid)

Variantes de color con fondo sólido y efectos hover

HTML 
<!-- Botón Primary -->
<button class="btn btn-primary">Primary</button>

<!-- Botón Success -->
<button class="btn btn-success">Success</button>

<!-- Botón Danger -->
<button class="btn btn-danger">Danger</button>

<!-- Todos los colores disponibles -->
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-info">Info</button>
<button class="btn btn-light">Light</button>
<button class="btn btn-dark">Dark</button>

¿Cómo funciona Bootstrap?

Bootstrap usa clases predefinidas que aplican estilos completos:

  • btn → Estilo base (padding, border-radius, cursor)
  • btn-primary → Define colores específicos
  • Los estilos se definen en las variables CSS de Bootstrap

Botones Outline

Solo borde con fondo transparente, perfecto para acciones secundarias

HTML

<!-- Outline Success -->
<button class="btn btn-outline-success">Success</button>

<!-- Outline Danger -->

<!-- Todos los outlines -->

<button class="btn btn-outline-warning">Warning</button>
<button class="btn btn-outline-info">Info</button>
<button class="btn btn-outline-dark">Dark</button>

Tip profesional: Los botones outline cambian a sólido al hacer hover. Son ideales para formularios o acciones secundarias donde no quieres distraer la atención.

Estados de Botones

Controla el comportamiento con estados activos, deshabilitados y loading

Clase: active
Atributo: disabled
Con spinner
HTML 
<!-- Estado activo -->
<button class="btn btn-primary active">Activo</button>

<!-- Estado deshabilitado -->
<button class="btn btn-primary" disabled>Deshabilitado</button>

<!-- Estado loading con spinner -->
<button class="btn btn-primary" type="button" disabled>
    <span class="spinner-border spinner-border-sm"></span>
    Cargando...
</button>

Importante: Los botones deshabilitados no son clickeables y tienen menor opacidad para indicar visualmente su estado.

Botones con Iconos

Mejora la usabilidad combinando iconos con texto

HTML 
<!-- Icono a la izquierda -->
<button class="btn btn-primary">
    <i class="fas fa-download me-2"></i>
    Descargar
</button>

<!-- Icono a la derecha -->
<button class="btn btn-outline-primary">
    Siguiente
    <i class="fas fa-arrow-right ms-2"></i>
</button>

<!-- Solo icono -->
<button class="btn btn-dark">
    <i class="fab fa-github"></i>
</button>

<!-- Utilidades de espaciado -->
<button class="btn btn-success">
    <i class="fas fa-check-circle me-2"></i>
    <span class="ms-1">Confirmar</span>
</button>

Espaciado con utilidades Bootstrap

  • me-2 → Margin end (derecha) de 0.5rem
  • ms-2 → Margin start (izquierda) de 0.5rem
  • mx-2 → Margin horizontal (izquierda y derecha)
  • my-2 → Margin vertical (arriba y abajo)

Grupos de Botones

Agrupa botones relacionados para mejorar la experiencia

HTML 
<!-- Grupo horizontal -->
<div class="btn-group" role="group">
    <button class="btn btn-primary">Izquierda</button>
    <button class="btn btn-primary">Centro</button>
    <button class="btn btn-primary">Derecha</button>
</div>

<!-- Grupo con iconos -->
<div class="btn-group" role="group">
    <button class="btn btn-outline-primary">
        <i class="fas fa-align-left"></i>
    </button>
    <button class="btn btn-outline-primary">
        <i class="fas fa-align-center"></i>
    </button>
    <button class="btn btn-outline-primary">
        <i class="fas fa-align-right"></i>
    </button>
</div>

<!-- Grupo vertical -->
<div class="btn-group-vertical" role="group">
    <button class="btn btn-outline-success">
        <i class="fas fa-bold"></i> Negrita
    </button>
    <button class="btn btn-outline-success">
        <i class="fas fa-italic"></i> Itálica
    </button>
</div>

Accesibilidad: Siempre usa role="group" en los grupos de botones para mejorar la accesibilidad con lectores de pantalla.

Botones en Tailwind CSS

Tailwind te da control total construyendo cada botón con clases de utilidad. No hay componentes predefinidos.

Personalizable Flexible Único

Botones Básicos (Solid)

Construye desde cero combinando clases de utilidad

HTML 
<!-- Botón Primary -->
<button class="bg-blue-500 hover:bg-blue-600 text-white 
               font-semibold py-3 px-6 rounded-lg 
               transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Primary
</button>

<!-- Botón Success -->
<button class="bg-emerald-500 hover:bg-emerald-600 
               text-white font-semibold py-3 px-6 
               rounded-lg transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Success
</button>

<!-- Botón Danger -->
<button class="bg-rose-500 hover:bg-rose-600 
               text-white font-semibold py-3 px-6 
               rounded-lg transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Danger
</button>

Anatomía de un botón Tailwind

bg-blue-500 Color de fondo
hover:bg-blue-600 Color en hover
text-white Color del texto
font-semibold Peso de fuente
py-3 px-6 Padding vertical/horizontal
rounded-lg Border radius grande
transition-all Transición suave
shadow-lg Sombra por defecto

Botones Outline

Fondo transparente con borde - Construye tu propio patrón

HTML 
<!-- Outline Primary -->
<button class="bg-transparent hover:bg-blue-500 
               text-blue-500 hover:text-white 
               font-semibold py-3 px-6 
               border-2 border-blue-500 rounded-lg 
               transition-all duration-300">
    Primary
</button>

<!-- Outline Success -->
<button class="bg-transparent hover:bg-emerald-500 
               text-emerald-500 hover:text-white 
               font-semibold py-3 px-6 
               border-2 border-emerald-500 rounded-lg 
               transition-all duration-300">
    Success
</button>

<!-- Outline Danger -->
<button class="bg-transparent hover:bg-rose-500 
               text-rose-500 hover:text-white 
               font-semibold py-3 px-6 
               border-2 border-rose-500 rounded-lg 
               transition-all duration-300">
    Danger
</button>

Patrón Tailwind: bg-transparent + border-2 + hover:bg-{color} + hover:text-{color}. ¡Puedes personalizar cada parte!

Botones con Gradientes

Crea efectos de gradiente únicos y modernos

HTML 
<!-- Gradiente Blue → Purple -->
<button class="bg-gradient-to-r from-blue-500 to-purple-600 
               hover:from-blue-600 hover:to-purple-700
               text-white font-semibold py-3 px-8 
               rounded-xl transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Blue → Purple
</button>

<!-- Gradiente Pink → Orange -->
<button class="bg-gradient-to-r from-pink-500 to-orange-400 
               hover:from-pink-600 hover:to-orange-500
               text-white font-semibold py-3 px-8 
               rounded-xl transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Pink → Orange
</button>

<!-- Gradiente Green → Cyan -->
<button class="bg-gradient-to-r from-emerald-400 to-cyan-500 
               hover:from-emerald-500 hover:to-cyan-600
               text-white font-semibold py-3 px-8 
               rounded-xl transition-all duration-300 
               shadow-lg hover:shadow-xl">
    Green → Cyan
</button>

Gradientes en Tailwind

  • bg-gradient-to-r → Gradiente de izquierda a derecha
  • from-{color} → Color de inicio del gradiente
  • to-{color} → Color de fin del gradiente
  • hover:from-{color} → Cambia color de inicio en hover
  • hover:to-{color} → Cambia color de fin en hover

¿Cuál elegir?

Elige Bootstrap si...

  • Quieres desarrollar rápido
  • Necesitas consistencia visual
  • Prefieres componentes predefinidos
  • Trabajas en equipo grande
  • Necesitas accesibilidad incluida

Elige Tailwind si...

  • Quieres diseño único
  • Necesitas control total
  • Te gusta construir desde cero
  • Prefieres utilidades sobre componentes
  • Buscas máximo rendimiento
